JAGDAMBA E-STORE V1

1) Open index.html and admin.html.
2) In app.js and admin.js replace:
   PASTE_YOUR_SUPABASE_URL_HERE
   PASTE_YOUR_SUPABASE_ANON_KEY_HERE

Get both from Supabase:
Project Settings -> API -> Project URL and anon/public key.

Do NOT put your Supabase service_role key in these files.

This version provides:
- Public product listing
- Search/category filtering
- Cart
- Admin login
- Admin product add/edit/delete
- Price, discount, delivery charge, stock, description and image URL management
